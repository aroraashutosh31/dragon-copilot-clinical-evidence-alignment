# Dragon Copilot Clinical Evidence Alignment

## Overview

Dragon Copilot Clinical Evidence Alignment is a Hackathon 2026 project focused
on helping clinicians connect AI-assisted clinical documentation with relevant,
trustworthy clinical evidence. The goal is to make supporting evidence easier
to find and review within the clinical workflow.

## Project Goals

- Surface evidence that is relevant to the clinical context.
- Preserve clinician review and decision-making.
- Make evidence sources clear, traceable, and easy to assess.
- Support safer, more informed clinical documentation workflows.

## Repository Status

This repository currently contains project documentation. Implementation details,
architecture, and setup instructions will be added as the project evolves.
